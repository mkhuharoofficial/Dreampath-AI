# Dreampath AI

**Your Career. Your Future. Your Dreampath.**

Dreampath AI is a free, AI-powered career guidance platform built for students in Pakistan. It helps students figure out which degree and career path actually fits them, instead of choosing based on guesswork or family pressure, by combining a short self-assessment with AI-generated, personalized recommendations.

## 📖 Overview

Many students, especially outside the big cities, don't have easy access to proper career counseling. Dreampath AI closes that gap by giving every student a free, instant, and personalized starting point for their career decision.

A student takes a short guided assessment covering their academic background, interests, and goals. The platform analyzes the answers and returns a ranked set of degree and career pathways that fit them, along with a full roadmap for each one, plus a built-in AI assistant for any follow-up questions.

## ✨ Features

- **Career self-assessment** — a short, guided set of questions covering academic background, interests, and goals.
- **AI-generated results profile** — instantly matches the student to their top career pathways, ranked by relevance.
- **Career roadmaps and blueprints** — degree-by-degree breakdowns across domains such as Medical and Health Sciences, Technology, Engineering, Business, and Law, grouped by qualification length.
- **AI career assistant (chatbot)** — a conversational assistant students can ask about admissions, test dates, fee structures, and scholarships.
- **Student dashboard** — a personal account area showing assessment history, saved reports, and counseling sessions.
- **Downloadable reports** — students can download a PDF handbook or summary of their results.

## ⚙️ How It Works

1. The student opens the platform and takes the free career self-assessment.
2. Answers are analyzed and matched against a set of degree and career pathways.
3. The student receives a results profile with their top matched pathways, ranked by fit.
4. The student can open any pathway to see a full blueprint, or download a PDF report of their results.
5. At any point, the student can continue the conversation with the AI career assistant for more specific questions about admissions, test dates, fees, or scholarships.

## 🚀 Getting Started

This is a web-based platform, so no installation is needed to use it — just visit the live site:

👉 [https://dreampathai.vercel.app/](https://dreampathai.vercel.app/)

To run the project locally from this repository:

```bash
git clone https://github.com/mkhuharoofficial/Dreampath-AI.git
cd Dreampath-AI
# open index.html in your browser, or serve the folder with a local server
```
